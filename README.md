# Govern & Grow — governgrow.com

Website for Govern & Grow: ISO 27001, ISO 42001 and DPDPA compliance consulting, plus digital transformation, ERP and operational efficiency.

Every page is self-contained (styles, scripts and logo are built in), so files can sit at the top level of the repository without any folders.

## Files

| File | Purpose |
|------|---------|
| index.html | Home page |
| thanks.html | Shown after the contact form is sent |
| 404.html | Page not found |
| logo-mark.svg | Logo, used by search engines (structured data) |
| sitemap.xml | List of pages for Google and Bing |
| robots.txt | Tells search engines they can crawl the site and where the sitemap is |
| CNAME | Custom domain for GitHub Pages |

## After the domain is live

1. Add governgrow.com to Google Search Console and submit https://governgrow.com/sitemap.xml.
2. Do the same in Bing Webmaster Tools.
3. Create a Google Business Profile for Govern & Grow.
